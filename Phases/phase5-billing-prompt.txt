Step 4: Domain services – plan, subscription, usage, quota

Implement:

IPlanService

- GetPlanForTenantAsync(tenantId)
- CRUD-like operations backing plan commands and queries.

ISubscriptionService

- AssignSubscriptionToTenantAsync(tenantId, planId, initialStatus, trialEnd, periodEnd)
- ChangeTenantPlanAsync(tenantId, newPlanId)
- MarkStatusAsync(tenantId, newStatus)

IUsageService

- RecordUsageEventAsync(tenantId, metricType)
  - Increment appropriate UsageCounter (monthly counters).
- RecalculateSnapshotForTenantAsync(tenantId)
  - Read:
    - UserCount from Identity module
    - ActiveUsersLast30Days from login/audit data or usage counters
    - ApplicationCount from Applications module
    - IdpConnectionCount from Federation module
    - LoginsThisMonth, ScimCallsThisMonth from UsageCounter
  - Store in TenantUsageSnapshot

IQuotaEnforcementService

Implement methods such as:

```csharp
Task CheckCanCreateUserAsync(Guid tenantId);
Task CheckCanCreateApplicationAsync(Guid tenantId);
Task CheckCanCreateIdpAsync(Guid tenantId);
Task CheckFeatureEnabledAsync(Guid tenantId, string featureKey);


Behavior:

Load current tenant Plan via IPlanService and TenantSubscription.

Evaluate PlanFeatures for relevant keys (MaxUsers, MaxApps, MaxIdps, OrgHierarchyEnabled, AdvancedSecurityEnabled, FederationEnabled, ScimEnabled, etc.).

Compare current usage (from UsageSnapshot or direct counts) against limits.

If Hard limit is exceeded:

Throw a business exception with a clear code (not a raw message).

If Soft limit is exceeded:

Set warning flags but do not block execution (for this phase, main behavior is detection).

All services must be fully implemented and must not rely on TODOs.

Step 6: Integration hooks – Identity, Applications, Federation, Login

Integrate IQuotaEnforcementService and IUsageService into existing modules.

Identity:

Before creating a new TenantUser:

Call IQuotaEnforcementService.CheckCanCreateUserAsync(tenantId).

After successful login (or via existing login pipeline):

Call IUsageService.RecordUsageEventAsync(tenantId, UsageMetricType.Logins).

Applications module:

Before creating a new ApplicationClient:

Call IQuotaEnforcementService.CheckCanCreateApplicationAsync(tenantId).

Federation module:

Before creating a new IdP/federation provider (SAML or OIDC):

Call IQuotaEnforcementService.CheckCanCreateIdpAsync(tenantId).

SCIM (optional in this phase):

For each SCIM call:

Call RecordUsageEventAsync(tenantId, UsageMetricType.ScimCalls).

Make sure these hooks are centralized and use IQuotaEnforcementService consistently instead of scattering limit checks across the code.
