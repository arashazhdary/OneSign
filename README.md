## 🌟 Overview | نمای کلی

<div dir="ltr">

**OneSign** is a production-ready, enterprise-grade Single Sign-On (SSO) and Identity & Access Management (IAM) platform built with .NET 10 and Next.js. It provides comprehensive identity management, security, and governance capabilities for multi-tenant SaaS applications.

</div>

<div dir="rtl">

**وان‌ساین** یک پلتفرم آماده تولید برای Single Sign-On (SSO) و مدیریت هویت و دسترسی (IAM) است که با .NET 10 و Next.js ساخته شده است. این پلتفرم قابلیت‌های جامع مدیریت هویت، امنیت و حاکمیت را برای برنامه‌های SaaS چند‌مستأجری فراهم می‌کند.

## 🏗️ Architecture | معماری

<div dir="ltr">

### Backend - Modular Monolith (.NET 10)

The backend follows a **Clean Architecture** pattern with **Domain-Driven Design (DDD)** principles, organized as a modular monolith:

#### Core Projects
- **`Onesign.Api`** - Main API project with controllers and middleware
- **`Onesign.Shared`** - Cross-cutting concerns (Result pattern, Pagination, Localization)
- **`Onesign.Data`** - Database context and shared data access
- **`Onesign.Sdk.DotNet`** - .NET SDK for client applications

#### Security Modules
- **`Onesign.Modules.Identity`** - User identity and authentication
- **`Onesign.Modules.Security`** - MFA, security policies, risk management
- **`Onesign.Modules.Authorization`** - RBAC, ABAC, policy engine
- **`Onesign.Modules.AccessRequests`** - Access request workflows
- **`Onesign.Modules.AdaptiveSecurity`** - Risk-based authentication
- **`Onesign.Modules.PrivilegedAccess`** - Privileged access management

## 🚀 Getting Started | شروع کار

<div dir="ltr">

### Prerequisites | پیش‌نیازها

- **.NET 10 SDK** - [Download](https://dotnet.microsoft.com/download)
- **Node.js 18+** and **npm** - [Download](https://nodejs.org/)
- **SQL Server** (or SQL Server Express) - [Download](https://www.microsoft.com/sql-server/sql-server-downloads)
- **Visual Studio 2022** or **VS Code** (optional)

### Backend Setup | راه‌اندازی بک‌اند

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd OneSign
   ```

2. **Configure database connection**
   
   Edit `src/Onesign.Api/appsettings.json`:
   ```json
   {
     "ConnectionStrings": {
       "DefaultConnection": "Server=YOUR_SERVER;Database=OnesignDbV2;Trusted_Connection=True;MultipleActiveResultSets=true"
     },
     "Jwt": {
       "SigningKey": "your-secret-signing-key-change-in-production-min-32-chars"
     },
     "Google": {
       "ClientId": "YOUR_GOOGLE_CLIENT_ID_HERE"
     }
   }
   ```

3. **Run database migrations**
   ```bash
   cd src/Onesign.Api
   dotnet ef database update
   ```

4. **Run the API**
   ```bash
   dotnet run
   ```
   
   The API will be available at:
   - HTTP: `http://localhost:7000`
   - HTTPS: `https://localhost:7001`
   - Swagger: `https://localhost:7001/swagger`

### Frontend Setup | راه‌اندازی فرانت‌اند

#### Login Portal | پورتال ورود

1. **Navigate to login portal**
   ```bash
   cd onesign-login-portal
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure API endpoint**
   
   Update API base URL in your environment or configuration files.

4. **Run development server**
   ```bash
   npm run dev
   ```
   
   Login Portal will be available at `http://localhost:3000`

#### Admin Portal | پورتال مدیریت

1. **Navigate to admin portal**
   ```bash
   cd onesign-admin-portal
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure API endpoint**
   
   Update API base URL in your environment or configuration files.

4. **Run development server**
   ```bash
   npm run dev
   ```
   
   Admin Portal will be available at `http://localhost:3001` (or next available port)

## 📚 API Endpoints | نقاط پایانی API

<div dir="ltr">

### Discovery & OIDC
- `GET /.well-known/openid-configuration` - OpenID Connect discovery
- `GET /connect/authorize` - Authorization endpoint
- `POST /connect/token` - Token endpoint
- `GET /connect/userinfo` - UserInfo endpoint
- `GET /.well-known/jwks.json` - JSON Web Key Set

### Authentication
- `POST /api/auth/login` - Password login
- `POST /api/auth/google-login` - Google social login
- `POST /api/auth/forgot-password` - Request password reset
- `POST /api/auth/reset-password` - Confirm password reset
- `POST /api/auth/complete-first-login` - Complete first login

### Admin Endpoints
- `GET /api/admin/tenants` - List all tenants
- `POST /api/admin/tenants` - Create new tenant
- `PATCH /api/admin/tenants/{tenantId}/status` - Update tenant status

### Tenant Endpoints
- `GET /api/tenant/users` - List tenant users
- `POST /api/tenant/users/invite` - Invite user to tenant
- `GET /api/tenant/users/{tenantUserId}` - Get user details
- `PATCH /api/tenant/users/{tenantUserId}/status` - Disable user
- `GET /api/tenant/applications` - List applications
- `POST /api/tenant/applications` - Create application
- `GET /api/tenant/applications/{id}` - Get application details
- `PUT /api/tenant/applications/{id}` - Update application
- `DELETE /api/tenant/applications/{id}` - Delete application
- `GET /api/tenant/settings` - Get tenant settings
- `PUT /api/tenant/settings/branding` - Update tenant branding
- `GET /api/tenant/audit` - Get audit events

## 🐛 Troubleshooting | عیب‌یابی

<div dir="ltr">

### Database Connection Issues | مشکلات اتصال پایگاه داده
- Verify SQL Server is running
- Check connection string in `appsettings.json`
- Ensure database exists or migrations are run

### Port Conflicts | تداخل پورت
- Default ports: 7000 (HTTP), 7001 (HTTPS)
- Change ports in `Properties/launchSettings.json`

### CORS Errors | خطاهای CORS
- Update CORS configuration in `Program.cs`
- Ensure frontend URLs are in allowed origins

### Migration Issues | مشکلات مایگریشن
- Ensure EF Core tools are installed: `dotnet tool install --global dotnet-ef`
- Check database permissions
- Verify connection string format

</div>

<div dir="rtl">

### مشکلات اتصال پایگاه داده
- بررسی کنید SQL Server در حال اجرا باشد
- رشته اتصال را در `appsettings.json` بررسی کنید
- اطمینان حاصل کنید پایگاه داده وجود دارد یا مایگریشن‌ها اجرا شده‌اند

### تداخل پورت
- پورت‌های پیش‌فرض: 7000 (HTTP), 7001 (HTTPS)
- پورت‌ها را در `Properties/launchSettings.json` تغییر دهید

### خطاهای CORS
- پیکربندی CORS را در `Program.cs` به‌روزرسانی کنید
- اطمینان حاصل کنید URLهای فرانت‌اند در مبداهای مجاز هستند

### مشکلات مایگریشن
- اطمینان حاصل کنید ابزارهای EF Core نصب شده‌اند: `dotnet tool install --global dotnet-ef`
- مجوزهای پایگاه داده را بررسی کنید
- فرمت رشته اتصال را بررسی کنید
