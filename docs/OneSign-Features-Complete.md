## معرفی سامانه

**OneSign** یک سامانه جامع مدیریت هویت و دسترسی سازمانی (Enterprise Identity and Access Management - IAM) است که امکانات کاملی برای:

- مدیریت چرخه حیات هویت کاربران
- کنترل دسترسی مبتنی بر نقش و سیاست
- احراز هویت چندعاملی
- Single Sign-On (SSO)
- مدیریت حساب‌های ویژه
- نظارت و ممیزی امنیتی
- یکپارچه‌سازی با سیستم‌های خارجی

فراهم می‌کند.

### ویژگی‌های کلیدی

| ویژگی | توضیحات |
|-------|---------|
| **Multi-Tenant** | پشتیبانی از چندین سازمان مستقل |
| **Multi-Region** | توزیع جغرافیایی داده‌ها |
| **Zero Trust** | معماری امنیتی بدون اعتماد |
| **Cloud-Native** | طراحی بومی ابری |
| **API-First** | طراحی مبتنی بر API |

---

## ماژول‌های اصلی

سامانه OneSign از ۳۲ ماژول اصلی تشکیل شده که در ۶ دسته‌بندی قرار می‌گیرند:

```
📦 Business (تجاری)
├── AccountCenter (مرکز حساب کاربری)
├── Applications (اپلیکیشن‌ها)
├── Billing (صورت‌حساب)
└── Organization (سازمان)

📦 Governance (حاکمیت)
├── Federation (فدراسیون)
├── Governance (حاکمیت هویت)
├── IdentityInsights (بینش هویتی)
└── IdentityLifecycle (چرخه حیات هویت)

📦 Integration (یکپارچه‌سازی)
├── Audit (ممیزی)
├── Copilot (دستیار هوشمند)
├── Developer (توسعه‌دهنده)
├── Extensibility (قابلیت توسعه)
├── NotificationCenter (مرکز اعلان)
└── Privacy (حریم خصوصی)

📦 Operations (عملیات)
├── Automation (اتوماسیون)
├── ChangeManagement (مدیریت تغییرات)
├── Hunting (شکار تهدید)
├── Incidents (رخدادها)
├── Insights (بینش‌ها)
└── Observability (قابلیت مشاهده)

📦 Platform (پلتفرم)
├── Crypto (رمزنگاری)
├── Deployment (استقرار)
├── MultiRegion (چندمنطقه‌ای)
├── Platform (پلتفرم)
└── Tenants (تنانت‌ها)

📦 Security (امنیت)
├── AccessRequests (درخواست دسترسی)
├── AdaptiveSecurity (امنیت تطبیقی)
├── Authorization (مجوزدهی)
├── Identity (هویت)
├── PrivilegedAccess (دسترسی ویژه)
└── Security (امنیت)
```

## ۱. مدیریت هویت (Identity Management)

### ۱.۱ مدیریت کاربران (User Management)

مدیریت کامل چرخه حیات کاربران از ایجاد تا غیرفعال‌سازی.

#### فیچرها:

| فیچر | توضیحات |
|------|---------|
| **ایجاد کاربر (User Creation)** | ایجاد کاربران جدید با اطلاعات کامل شامل نام، ایمیل، شماره تماس و اطلاعات سازمانی |
| **ویرایش کاربر (User Update)** | به‌روزرسانی اطلاعات کاربران موجود |
| **غیرفعال‌سازی کاربر (User Deactivation)** | غیرفعال کردن موقت یا دائم حساب کاربری |
| **حذف کاربر (User Deletion)** | حذف کامل حساب کاربری با رعایت سیاست‌های حفظ داده |
| **جستجوی کاربر (User Search)** | جستجوی پیشرفته با فیلترهای متعدد |
| **دعوت کاربر (User Invitation)** | ارسال دعوت‌نامه ایمیلی برای ثبت‌نام |
| **تخصیص نقش (Role Assignment)** | اختصاص نقش‌های مختلف به کاربران |
| **تخصیص واحد سازمانی (OrgUnit Assignment)** | تعیین واحد سازمانی اصلی و فرعی |
| **مشاهده فعالیت‌ها (Activity Viewing)** | مشاهده تاریخچه فعالیت‌های کاربر |
| **مدیریت پروفایل (Profile Management)** | ویرایش اطلاعات پروفایل توسط کاربر |
| **تغییر رمزعبور (Password Change)** | تغییر رمزعبور با رعایت سیاست‌های امنیتی |
| **بازنشانی رمزعبور (Password Reset)** | بازنشانی رمزعبور توسط ادمین |
| **قفل حساب (Account Lock)** | قفل کردن حساب پس از تلاش‌های ناموفق |
| **باز کردن قفل (Account Unlock)** | باز کردن حساب قفل شده توسط ادمین |

#### زیرفیچرها:

- **تایید ایمیل (Email Verification)**: ارسال لینک تایید ایمیل
- **تایید شماره موبایل (Phone Verification)**: ارسال کد تایید SMS
- **مدیریت عکس پروفایل (Avatar Management)**: آپلود و مدیریت تصویر پروفایل
- **تنظیمات اعلان (Notification Preferences)**: تنظیم ترجیحات دریافت اعلان
- **تنظیمات زبان (Language Settings)**: انتخاب زبان رابط کاربری
- **تنظیمات منطقه زمانی (Timezone Settings)**: تنظیم منطقه زمانی

### ۱.۲ مدیریت واحدهای سازمانی (Organization Units)

ساختار سلسله‌مراتبی سازمان برای مدیریت بهتر کاربران و دسترسی‌ها.

#### فیچرها:

| فیچر | توضیحات |
|------|---------|
| **ایجاد واحد سازمانی (Create OrgUnit)** | ایجاد واحد جدید با نام، کد و واحد والد |
| **ویرایش واحد سازمانی (Update OrgUnit)** | به‌روزرسانی اطلاعات واحد موجود |
| **حذف واحد سازمانی (Delete OrgUnit)** | حذف واحد با بررسی وابستگی‌ها |
| **مشاهده درختی (Tree View)** | نمایش ساختار سلسله‌مراتبی |
| **جابجایی واحد (Move OrgUnit)** | تغییر والد یک واحد سازمانی |
| **تخصیص کاربر (Assign Users)** | اختصاص کاربران به واحد |
| **تخصیص مدیر (Assign Manager)** | تعیین مدیر واحد سازمانی |
| **مشاهده اعضا (View Members)** | لیست کاربران عضو واحد |
| **محدوده دسترسی (Access Scope)** | تعریف محدوده دسترسی کاربران |

#### زیرفیچرها:

- **کد واحد (OrgUnit Code)**: کد یکتا برای هر واحد
- **سطح واحد (OrgUnit Level)**: سطح در سلسله‌مراتب
- **وضعیت واحد (OrgUnit Status)**: فعال/غیرفعال
- **متادیتا (Metadata)**: اطلاعات اضافی سفارشی

### ۱.۵ چرخه حیات هویت (Identity Lifecycle)

مدیریت خودکار چرخه حیات کاربران از ورود تا خروج.

#### فیچرها:

| فیچر | توضیحات |
|------|---------|
| **ورود کاربر (Joiner)** | فرآیند ورود کاربر جدید |
| **جابجایی کاربر (Mover)** | فرآیند تغییر واحد/نقش |
| **خروج کاربر (Leaver)** | فرآیند خروج کاربر |
| **بسته‌های دسترسی (Access Packages)** | مجموعه دسترسی‌های از پیش تعریف‌شده |
| **قوانین تخصیص (Assignment Rules)** | قوانین خودکار تخصیص دسترسی |
| **یکپارچه‌سازی HR (HR Integration)** | اتصال به سیستم منابع انسانی |
| **رویدادهای چرخه حیات (Lifecycle Events)** | ثبت رویدادهای چرخه حیات |
| **سیاست‌های چرخه حیات (Lifecycle Policies)** | تعریف سیاست‌های اتوماتیک |

#### زیرفیچرها:

- **تاریخ شروع (Start Date)**: تاریخ شروع همکاری
- **تاریخ پایان (End Date)**: تاریخ پایان همکاری
- **دوره آزمایشی (Probation Period)**: مدیریت دوره آزمایشی
- **انتقال دسترسی (Access Transfer)**: انتقال دسترسی‌ها هنگام جابجایی
- **لغو دسترسی (Access Revocation)**: لغو خودکار دسترسی‌ها هنگام خروج
